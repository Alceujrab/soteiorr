RR VEÍCULOS — PACOTE DE ÍCONES
================================

Base: logomarca fornecida pelo cliente.

Incluído:
- favicon.ico — 16/32/48 px
- favicon PNG — 16, 32, 48 e 96 px
- Apple Touch Icon — 180 px
- Android/PWA — 192 e 512 px
- Android Maskable — 192 e 512 px
- Microsoft Tile — 150 px
- Safari pinned tab — SVG monocromático
- site.webmanifest
- index-icons.html com as tags <head> prontas

INSTALAÇÃO:
1. Copie a pasta "icons" para a raiz do site.
2. Coloque o conteúdo de index-icons.html dentro do <head>.
3. Se preferir outra pasta, ajuste os caminhos /icons/ nas tags e no manifest.
